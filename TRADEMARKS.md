# The Zeropunch™ name

The code of Zeropunch is free software under the
[GNU Affero General Public License v3.0](LICENSE). That license covers the
code — not the names **Zeropunch™** and **Dropnook™** or their logos, which
identify this project and its official releases. (AGPL-3.0, section 7(e),
allows exactly this.)

**You may**

* use, change and share the code as the license allows;
* say that your work is *based on Zeropunch*, *works with Zeropunch* or is a
  *fork of Zeropunch*;
* pass on the official, unchanged releases under their name;
* write about Zeropunch, review it, show it in videos and tutorials.

**Please don't**

* call a changed version, a fork or a service built on it "Zeropunch" or a
  name easily mistaken for it, or use the logo for it;
* suggest that the project endorses you or your product when it does not.

Forks are welcome — pick a name of your own and mention that it is based on
Zeropunch, with a link to <https://github.com/dropnook/zeropunch>.

If you are unsure, open an issue and ask.
